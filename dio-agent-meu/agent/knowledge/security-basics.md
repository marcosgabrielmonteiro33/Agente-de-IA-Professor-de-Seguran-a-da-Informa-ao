# Fundamentos de Segurança da Informaçao

## Vulnerabilidade 

Uma vulnerabilidade é uma falha em um sistema, aplicaçao ou processo que pode permitir comportamentos indesejados.

## Ameaça 

Uma ameaça representa algo que pode explorar uma vulnerabilidade.

## Risco 

Risco é a combinaçao entre:

- probabilidade;
- impacto.

## Principios de Segurança 

### Confidencialidade

Garantir que Informaçoes nao sejam alteradas indevidamente.


### Integraçao

Garantir que informaçoes nao sejam aleradas indevidamente.

### Disponibilidade

Garantir que sistemas continuem funcionando.

## Boas praticas

- manter sistemas atualizado;
- ultilizar autenticaçao forte;
- aplicar menor privilegio;
- monitorar eventos;
- realizar backups;
- corrigir vulnerabilidades conhecidas
